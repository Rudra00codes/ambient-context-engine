## Key Observations & Baseline Analysis

1. **Temporal Filtering Weakness (Thesis Validation):** In naive RAG, hybrid queries that contain both temporal ('around 4:15 PM') and semantic constraints rely entirely on whole-query embedding similarity and full-text search. As expected by the core thesis, top-k retrieval is easily dominated by semantically similar captures from other sessions rather than the exact target window.
2. **Ambiguous / Refusal Cases:** Queries with `should_refuse: true` verify whether the system hallucinates when context is absent or outside the captured dataset. Capturing ungrounded responses directly highlights the need for the low-confidence refusal path.
3. **Next Steps:** Implement session segmentation (Tier 2, Problem 2) to collapse contiguous near-duplicates and temporal query decomposition (Tier 2, Problem 1) to separate time filtering from semantic ranking.
